# Identity Fixtures

- `oq003_cases.v0.1.json` — accepted semantic decision cases for OQ-003. These are classification/conformance scenarios.
- `identity_contract_examples.v0.2.json` — synthetic JSON instances used to validate the BoatModel, BoatDesign draft and ResolvedConfiguration draft schemas. They are not factual sailboat records and must never enter production data.

Future implementation tests should reference the stable requirement IDs in `specs/REQUIREMENTS.md` and use these fixtures as regression inputs where appropriate.
