## Reproducibility gate

The repository MUST contain a valid `uv.lock` generated by an accepted uv 0.12.x tool, currently pinned to uv 0.12.5 for the bootstrap baseline. CI MUST execute `uv lock --check` and `uv sync --locked --all-groups`.

The artifact-generation sandbox used for this repository snapshot has no package-index network access and therefore cannot truthfully resolve and generate a real lockfile. No placeholder or hand-authored lockfile is permitted.

On the first networked developer/CI environment:

```bash
uv python install 3.14
uv lock
uv sync --locked --all-groups
```

Then commit `uv.lock` and run the full CI-equivalent command set from `CONTRIBUTING.md`.

## Exit criteria

Stage 0.3 becomes DONE only when:

1. `uv.lock` exists and `uv lock --check` succeeds;
2. locked sync succeeds on Linux and Windows;
3. formatter/linter/type/test/coverage gates pass;
4. repository/schema/fixture validation passes;
5. dependency audit passes or an explicitly reviewed exception is documented.
