## B04-001 — Sadler 34

**Independent sources**
- Yachtsnet archive: https://www.yachtsnet.co.uk/archives/sadler-34/sadler-34.htm
- Lucas Yachting Sadler archive: https://www.lucasyachting.co.uk/sadler-and-starlight/sadler-34-yacht/
- Practical Boat Owner comparison: https://www.pbo.co.uk/boats/draft-sadler-34-98740

**Observed evidence**
- Yachtsnet gives principal dimensions/mass and documents deep fin, shallow fin and bilge/twin-keel forms, plus a small number with centreboards inside shallow fins.
- Later redesigned deep-fin keels and possible retrofits are documented.
- Lucas Yachting describes four keel options and a full-depth skeg-supported rudder.
- `34SE` is described as an equipment/fitout upgrade using the same hull and rig.

**Benchmark problem:** factory option space plus later keel evolution; `SE` suffix should not automatically create a new BoatDesign.

**Reference crosscheck:** strong baseline agreement but materially incomplete option coverage. No reference values retained.

## B04-005 — F-27 Sport Cruiser / Corsair F-27

**Independent sources**
- Robert Perry / SAILING retrospective: https://sailingmagazine.net/article-1785-f-27.html
- Practical Sailor: https://www.practical-sailor.com/sailboat-reviews/f-27/
- Farrier history: https://www.multihull.nl/multihulls/used-multihulls/F-27%20General/CorsairF27History.html
- Corsair Germany Atlantic-crossing record: https://www.corsair-germany.com/abenteuer_atlantik/abenteuer_atlantik.php

**Observed evidence**
- Ian Farrier design with mid-1980s production and roughly 450 examples in specialist history.
- Independent sources expose sailing beam, folded beam, board-up/down draft, displacement and sail-area information.
- Folded geometry is inherent to the Farrier folding system, not a cosmetic transport note.
- Secondary sources show some mass drift across publications.

**Benchmark problem:** sailing/folded geometry state, board state and historical naming must coexist without duplicate identity or one hidden displacement scalar.

**Reference crosscheck:** strong ordinary-field agreement; reference notes also expose folded-beam ambiguity. No reference values retained.

## B04-006 — Prout Snowgoose 37 / Snowgoose 37 Elite

**Independent sources**
- SAILING Magazine Snowgoose review: https://sailingmagazine.net/article-permalink-554.html
- De Valk late-1990s listing: https://www.devalk.nl/en/yachtbrokerage/420130/PROUT-SNOWGOOSE-37.html

- Boatshed Elite record: https://hamble.boatshed.com/prout_snowgoose_37_elite-boat-170057.html

**Observed evidence**
- Earlier Snowgoose 37 material describes molded stub keels and a lighter baseline.
- The later **Elite** is materially wider/evolved, not a harmless marketing suffix.
- Late individual-hull records labelled simply `Snowgoose 37` can be physically closer to the Elite family than the earlier baseline.

**Benchmark problem:** model/evolution identity must be resolved before projecting a late individual hull onto the original baseline.

**Reference crosscheck:** reference database also separates Snowgoose 37 from Snowgoose 37 Elite, supporting the independently discovered generation boundary. No reference dimensions/mass retained.

**Independent sources**
- Westerly Owners Association Wiki: https://wiki.westerly-owners.co.uk/index.php?title=Konsort
- WOA brochure archive: https://wiki.westerly-owners.co.uk/index.php?title=Westerly_Brochures

**Observed evidence**
- WOA lists **fin / twin / lifting** keel variants and gives configuration-specific draft/ballast information.
- WOA and Yachtsnet provide broadly consistent production history while differing in exact published count phrasing.
- Yachting Monthly confirms the multiple keel forms and transom-hung rudder.

**Benchmark problem:** lifting configuration changes both draft state and ballast; production count/displacement conflict among reputable sources needs review rather than forced resolution.

**Reference crosscheck:** partial/incomplete; reference foregrounds less of the configuration space and disagrees on some scalar metadata. No reference values retained.

## B04-008 — Heavenly Twins 26 → New 27 lineage

**Independent sources**
- HTCCA model history: https://htcca.co.uk/ht-26-27/
- HTCCA technical description: https://htcca.co.uk/ht-description/

**Observed evidence**
- Owners association preserves Mk1, Mk2, Mk2A, Mk3, Mk4 and later New 27/HT27 changes.
- Mk2A introduced a new hull mould, longer keels and central nacelle; Mk3 retained that hull but added a new deck mould; later forms changed deck/interior geometry.
- New 27 data includes multihull dimensions/mass and separated sail components.

**Benchmark problem:** Mk labels have unequal technical significance; new hull mould and keel changes are stronger generation evidence than interior/deck-only changes.

**Reference crosscheck:** broadly consistent generation distinctions; outcome only retained.

# Wave 04 findings

1. Reference-database duplicate/identity conflicts are real.
2. Commercial suffixes vary from fitout-only to material hull evolution.
3. Keel option space often changes more than draft.
4. Long-running models require evidence-driven generation decisions.
5. Legacy multihull geometry is strongly stateful.
6. Late individual hulls can masquerade as baseline design records.
7. Chronology needs explicit event semantics.
8. Weak-primary-source designs remain researchable with lower-confidence archival/community chains.
